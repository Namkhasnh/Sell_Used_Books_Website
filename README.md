# Sell Used Books Website

- `backend/`: NestJS API.
- `frontend/`: React application.

## Lưu thay đổi lên GitHub

Mở terminal tại thư mục `Sell_Used_Books` rồi chạy:

```sh
git status
git add backend/ frontend/ README.md .gitignore
git commit -m "Mô tả thay đổi"
git push
```

Cả hai phần dùng chung một repository và nhánh `demo_git`.
Không cần chạy `git init` trong các thư mục con.
Xem README và scripts trong package.json của từng phần để chạy ứng dụng.
